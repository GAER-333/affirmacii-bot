# Настройка бота в BotFather

Адрес приложения: **https://gaer-333.github.io/affirmacii-bot/**

Всё ниже можно поменять в любой момент: `/mybots` → выбрать бота → **Edit Bot** / **Bot Settings**.

## 1. Создать бота
`/newbot` → имя → username (обязательно на `bot`, например `affirmacii_bot`).
BotFather пришлёт **токен** — никому его не показывайте. Сохраните в надёжном месте, понадобится позже.

## 2. Имя (Edit Name, до 64 символов)
```
Аффирмации
```

## 3. «О боте» — короткий текст в профиле (Edit About, до 120 символов)
```
Аффирмации голосом под спокойную музыку — утром, днём и перед сном. Нажмите «Открыть».
```

## 4. Описание — видно до нажатия «Старт» (Edit Description, до 512 символов)
```
🌅 Аффирмации на каждый момент дня

Спокойный голос проговаривает поддерживающие фразы под мягкую музыку:
• утром — чтобы настроиться на день
• днём — чтобы выдохнуть и собраться
• ночью — чтобы отпустить день и уснуть

Выбирайте женский или мужской голос, добавляйте свои фразы, ставьте таймер сна.

Нажмите «Открыть», чтобы начать 🌙
```

## 5. Кнопка меню (Bot Settings → Menu Button → Configure menu button)
- адрес: `https://gaer-333.github.io/affirmacii-bot/`
- название кнопки: `Слушать`

## 6. Главное мини-приложение (Bot Settings → Configure Mini App → Enable Mini App)
- адрес: `https://gaer-333.github.io/affirmacii-bot/`

Появится кнопка «Открыть» в профиле бота и ссылка вида `t.me/ИМЯ_БОТА?startapp`.

## 7. Аватарка (Edit Botpic)
Квадратная картинка, лучше от 512×512.

---

Пока у бота нет своего сервера, на сообщения (в том числе `/start`) он не отвечает —
приложение открывается кнопкой меню или «Открыть». Ответы на `/start` — следующий этап.
