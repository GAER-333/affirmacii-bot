## Этап 3. Свои фразы голосом Яндекса (SpeechKit) ← сейчас
Главный принцип: фраза озвучивается **один раз — при добавлении**, а не во время прослушивания.
Дальше это обычный mp3, как готовые 60 фраз: попадает в очередь (iPhone/компьютер) и в склеенную
дорожку (Android), звучит в фоне. «Прямого эфира» нет.

Схема:
```
Приложение ──(текст, голос, подпись Telegram)──► Облачная функция Яндекса
                                                   │ 1. проверяет подпись Telegram (только настоящие пользователи)
                                                   │ 2. лимиты: длина ≤ 200, не больше N фраз в день
                                                   │ 3. файл уже есть в хранилище? → сразу отдаёт адрес
                                                   │ 4. нет → SpeechKit озвучивает → mp3 в хранилище
Приложение ◄──────────── адрес mp3 ────────────────┘
```
- Ключей в коде нет: функция работает от «сервисного аккаунта» Яндекса и получает доступ к SpeechKit сама.
  Единственный секрет — токен бота (для проверки подписи), хранится в настройках функции.
- Имя файла = отпечаток (текст + голос + настройки) → одинаковая фраза озвучивается один раз на всех,
  на другом устройстве та же фраза находится без повторной оплаты.

Решения (29.10.2026):
- озвучивается только выбранный голос; второй — когда пользователь переключит голос (это всегда в открытом приложении);
- лимиты в настройках функции, меняются без переписывания приложения: 40 новых фраз в день на человека,
  общий предел ~1800 озвучек в месяц (≈ 300 ₽ — как бюджет);
- для пользователей бесплатно, пока приложение в разработке.
