# Аффирмации — Telegram Mini App

Мини-приложение для Telegram: пользователь добавляет свои аффирмации, а приложение
проговаривает их голосом под спокойную фоновую музыку.

## Как это устроено

```
Пользователь ──► Telegram-бот ──► кнопка «Открыть» ──► веб-страница на хостинге
                (создан в BotFather)                    (index.html + app.js + style.css)
```

- **Мини-приложение** — обычная веб-страница. Telegram открывает её во встроенном браузере.
- **Хостинг** — место в интернете, где лежит страница. Telegram требует адрес с `https://`.
  Используем **GitHub Pages**: бесплатно, есть HTTPS, а обновление — одна команда `git push`.
- **Бот** на первом этапе не требует своего сервера и кода. Через BotFather мы просто привяжем
  к нему адрес страницы.

## Файлы проекта

| Файл         | Что внутри                                                        |
|--------------|-------------------------------------------------------------------|
| `index.html` | Разметка страницы: переключатель, заголовки, кнопки               |
| `style.css`  | Оформление: три темы (утро / день / ночь), шрифты, отступы        |
| `data.js`    | Тексты аффирмаций для каждого времени суток                       |

| `audio/`     | Озвучка фраз и фоновая музыка в mp3 (см. `audio/README.md`)       |

## Шаг 1. Выложить проект на GitHub Pages

1. Зарегистрируйтесь на https://github.com (если ещё нет аккаунта).
2. Создайте новый репозиторий: кнопка **New** → имя, например `affirmacii-bot` →
   **Public** → **Create repository**. Галочки «Add README» не ставьте.
3. В папке проекта выполните (подставьте свой логин вместо `ВАШ_ЛОГИН`):
   ```bash
   git remote add origin https://github.com/ВАШ_ЛОГИН/affirmacii-bot.git
   git push -u origin main
   ```
   При первом push Git откроет окно входа в GitHub, войдите через браузер.
4. На GitHub в репозитории: **Settings → Pages → Build and deployment**:
   Source = **Deploy from a branch**, Branch = **main**, папка **/ (root)** → **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу
   `https://ВАШ_ЛОГИН.github.io/affirmacii-bot/`. Проверьте его в браузере.

## Шаг 2. Создать бота в BotFather

1. В Telegram откройте [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Введите отображаемое имя (например, «Аффирмации»), затем username, который
   должен заканчиваться на `bot` (например, `my_affirmacii_bot`).
3. BotFather пришлёт **токен**, длинную строку вида `123456:ABC...`.
   **Никому его не показывайте и не коммитьте в репозиторий.** Пока он не нужен,
   но понадобится, когда бот начнёт отвечать на сообщения.

## Шаг 3. Подключить мини-приложение к боту

**Кнопка меню** (слева от поля ввода в чате с ботом):
1. В BotFather: `/mybots` → выберите бота → **Bot Settings** → **Menu Button** →
   **Configure menu button**.
2. Отправьте адрес `https://ВАШ_ЛОГИН.github.io/affirmacii-bot/`.
3. Отправьте название кнопки, например `Слушать`.

**Главное мини-приложение** (кнопка «Открыть» в профиле бота, ссылка `t.me/бот?startapp`):
1. `/mybots` → бот → **Bot Settings** → **Configure Mini App** → **Enable Mini App**.
2. Отправьте тот же адрес.

Готово: откройте чат с ботом и нажмите кнопку меню.

## Как обновлять приложение

После любых изменений в файлах:
```bash
git add .
git commit -m "Что изменили"
git push
```
Через минуту GitHub Pages обновит сайт. Если Telegram показывает старую версию,
закройте мини-приложение и откройте снова.

## Что уже адаптировано под Telegram

- Подключён SDK `telegram-web-app.js`.
- Приложение разворачивается на весь экран, шапка Telegram окрашена в цвет фона.
- Цвет шапки Telegram меняется вместе с темой (утро / день / ночь).
- Лёгкая вибрация при переключении времени суток и при запуске.

## Озвучка

Фразы проигрываются из готовых mp3-файлов (озвучены заранее в ElevenLabs),
поэтому голос одинаково звучит на всех устройствах, включая Android.
Пока файлов нет, фразы читает встроенный голос устройства. Он работает на iPhone
и компьютере, но в Telegram на Android часто молчит.
