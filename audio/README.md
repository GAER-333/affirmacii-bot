# Аудиофайлы

Сюда кладутся готовые mp3. Приложение находит их по имени, поэтому названия важны.

```
audio/
├── morning/        ← озвучка утренних фраз
│   ├── 01.mp3      ← фраза №1 из набора «Утро» в data.js
│   ├── 02.mp3
│   └── ...
├── day/            ← озвучка дневных фраз (01.mp3, 02.mp3, ...)
├── night/          ← озвучка ночных фраз (01.mp3, 02.mp3, ...)
└── music/
    ├── morning.mp3 ← фоновая музыка для утра (играет по кругу)
    ├── day.mp3
    └── night.mp3
```

- Номер файла = номер фразы в списке `data.js` (первая фраза → `01.mp3`).
- Если какого-то файла нет, ничего не сломается: фраза прочитается голосом устройства,
  а вместо музыки заиграет мягкий синтезатор.
- Если поменяли текст фразы в `data.js`, не забудьте переозвучить её файл.

## Как озвучить в ElevenLabs

1. elevenlabs.io → **Text to Speech**.
2. Выберите голос, модель с поддержкой русского (Multilingual).
3. Вставьте одну фразу → **Generate** → скачайте mp3.
4. Переименуйте по номеру (`01.mp3`) и положите в нужную папку.

Совет: для спокойного звучания уменьшите **Speed** и увеличьте **Stability**,
а в конце фразы можно поставить многоточие — голос закончит мягче.

## Музыка

Подойдут спокойные треки без авторских ограничений (например, с pixabay.com/music,
раздел Ambient / Meditation). Лучше брать треки, которые плавно звучат по кругу.
Громкость музыки настраивается в `app.js` (`MUSIC_VOLUME_DB`).
