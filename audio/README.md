# Аудиофайлы

Сюда кладутся готовые mp3. Приложение находит их по имени, поэтому названия важны.

```
audio/
├── female/             ← женский голос
│   ├── morning/        ← утренние фразы
│   │   ├── 01.mp3      ← фраза №1 из набора «Утро» в data.js
│   │   ├── 02.mp3
│   │   └── ...
│   ├── day/            ← дневные фразы (01.mp3, 02.mp3, ...)
│   └── night/          ← ночные фразы (01.mp3, 02.mp3, ...)
├── male/               ← мужской голос, такая же структура
└── music/
    ├── morning.mp3 ← фоновая музыка для утра
    ├── morning-2.mp3 ← (необязательно) второй трек утра, можно до 5 штук
    ├── day.mp3
    ├── night.mp3
    └── night-2.mp3
```

Треки одного времени суток играют по очереди и по кругу. Соседние треки плавно
накладываются друг на друга (4 секунды), тишина в начале и конце файла обрезается сама,
а громкость разных треков выравнивается автоматически.

- Номер файла = номер фразы в списке `data.js` (первая фраза → `01.mp3`).
- Если какого-то файла нет, ничего не сломается: приложение возьмёт фразу другим голосом
  (женским вместо мужского или наоборот), а если нет и её — прочитает голосом устройства.
  Вместо отсутствующей музыки заиграет мягкий синтезатор.
- Если поменяли текст фразы в `data.js`, не забудьте переозвучить её файл.
- Голоса записаны с разной громкостью, поэтому в `levels.js` для каждого набора
  записана поправка в дБ — приложение выравнивает их при воспроизведении.
  Заменили запись набора — громкость нужно измерить заново и обновить поправку.

## Озвучка: голоса Яндекс SpeechKit

Сейчас фразы озвучены голосами Яндекса (каждая фраза — отдельный запрос, резать ничего не нужно):

| | Утро | День | Ночь |
|---|---|---|---|
| female | Замира (`zamira_ru`, дружелюбный, 0,89) | Замира | Юлдуз (`yulduz_ru`, дружелюбный, 0,89) |
| male | Ермил (`ermil`, радостный, 0,89) | Ермил | Денис (`denis`, LiveTTS, разговорный) |

Переозвучить: впишите ключ в `.env` (`YANDEX_API_KEY=...`) и запустите из папки проекта
`node tools/yandex-voice.js --force` (все 60 фраз, ~12 ₽) или с `--gender`, `--time`, `--only 3,5`.
Голоса меняются в начале `tools/yandex-voice.js`. После замены голоса измерьте громкость заново (`levels.js`).

Прежние записи ElevenLabs (Cherry, Hazel, Kate, VASKO, Anton, Maksim) сохранены в git, метка `elevenlabs-voices`.

## Музыка

Подойдут спокойные треки без авторских ограничений (например, с pixabay.com/music,
раздел Ambient / Meditation): без вокала, без резких ударных, от 2–3 минут.
Насколько музыка тише голоса, настраивается в `app.js` (`MUSIC_VOLUME_DB`).
